# EGO: 混沌脉冲网络通过局部规则涌现感觉运动功能

## 这是什么

一个纯脉冲神经网络（SNN），不使用奖惩机制、不使用全局监督学习，仅靠局部规则（STDP + Eligibility Trace + 稳态可塑性）和物理引导，学会了"看到形状 → 发出对应声音"的跨模态感觉运动映射。

## 核心结果

| 指标 | 数值 |
|---|---|
| 10种子平均相关系数 | 0.865 ± 0.022 |
| 95%置信区间 | [0.848, 0.881] |
| vs RLS基线 | 0.865 vs 0.382 (p=0.0029) |
| 泛化能力（未见形状） | 0.763-0.821 |
| 网络规模 | 1000脉冲神经元 |

## 这跟现有方法的区别

| 要素 | 本项目 | 现有工作 |
|---|---|---|
| 学习规则 | STDP（局部） | RLS/反向传播（全局） |
| 奖惩机制 | 无 | 有（多巴胺/奖励调制） |
| 引导方式 | 物理引导（目标电流驱动输出） | 随机探索或误差反馈 |
| 跨模态 | 视觉→声音 | 单模态或视觉→运动 |

## 文件结构

- `force_phase1.py` — Phase 1: FORCE基线（RLS读出层）
- `force_phase2.py` — Phase 2: 加视觉输入，视觉→声音映射
- `force_phase3.py` — Phase 3: 用STDP替换RLS
- `rigorous_experiments.py` — 严格学术实验（6组实验）
- `data_rigorous/` — 实验结果数据

## 运行方法

```bash
python force_phase3.py
python rigorous_experiments.py
```

## 依赖

- Python 3.12
- NumPy
- SciPy

## 核心原则

- 混沌储备池权重固定（天生的神经通路）
- 只有读出层权重可塑（STDP学习）
- 无奖惩、无全局误差信号
- 物理引导：训练时注入目标电流驱动输出神经元，测试时撤掉
