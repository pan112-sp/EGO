# EGO: 局部可塑性规则匹配全局优化——混沌脉冲网络的感觉运动学习

## 这是什么

一个纯脉冲神经网络（SNN），不使用奖惩机制、不使用梯度反向传播，仅靠局部突触可塑性规则（STDP + 稳态可塑性）和教师强制引导，学会了"看到形状 → 发出对应声音"的跨模态感觉运动映射。

关键发现：纯局部规则（每个突触只用1个标量信息）达到了跟全局优化方法（岭回归/RLS，使用1000x1000协方差矩阵）统计上等效的性能。

## 核心结果

| 指标 | 数值 |
|---|---|
| STDP方法（10种子平均） | 0.865 ± 0.022 |
| 离线岭回归（理论上限） | 0.873 ± 0.010 |
| 在线RLS/FORCE（修正版） | 0.875 ± 0.009 |
| STDP vs 岭回归 | p=0.29, 不显著 |
| STDP vs RLS | p=0.21, 不显著 |
| 泛化能力（未见形状） | 0.763-0.821 |
| 位置偏移泛化 | 0.794±0.087 |
| 大小缩放泛化 | 0.549±0.245 |
| 网络规模 | 1000脉冲神经元 |

## 核心贡献

局部突触可塑性规则（STDP）在信息严重不对称的条件下——每个突触只知道前后两个神经元的放电时序，而全局方法知道整个网络的状态——达到了统计上等效的学习效果。这说明信息瓶颈不是感觉运动映射学习的根本障碍。

## 这跟现有方法的区别

| 要素 | 本项目 | 现有工作 |
|---|---|---|
| 学习规则 | STDP（局部，1标量/突触） | RLS/梯度（全局，1000x1000矩阵） |
| 奖惩机制 | 无 | 有（多巴胺/奖励调制） |
| 引导方式 | 教师强制（目标电流驱动输出神经元活动） | 随机探索或误差反馈 |
| 权重更新 | STDP按脉冲时序局部更新 | 误差梯度反向传播 |
| 跨模态 | 视觉→声音 | 单模态或视觉→运动 |

## 文件结构

- `force_phase3.py` — 核心代码：STDP+稳态可塑性学习视觉→声音映射

- `test_improvements.py` — 论文修订实验（RLS PSP扫描、脉冲频率读出对比）

- `workshop_paper_draft.md` — 论文初稿
- `SNUFA_2026_abstract.md` — SNUFA 2026摘要投稿

## 依赖

## 核心原则

- 混沌储备池权重固定（谱半径5.0，天生的神经通路）
- 只有读出层权重可塑（STDP学习）
- 无奖惩信号、无梯度反向传播
- 教师强制：训练时注入目标电流驱动输出神经元活动，STDP从放电相关性中自主学习
- 测试时撤掉一切引导，网络独立生成输出
